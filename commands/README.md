# commands/

`commands.sh` is a **reference listing** of the commands used in this lab, in order, with comments — it is **not** meant to be run start-to-finish as one script.

Two steps require manual/interactive action and are clearly marked:
- Setting the password (`passwd`) — requires typing and confirming a password at a prompt.
- Editing `report.txt` in `nano` — requires manual keystrokes inside the editor.

Run the non-interactive blocks yourself in order, and perform the marked steps manually when you reach them.
